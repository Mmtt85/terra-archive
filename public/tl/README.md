# 테라 아카이브 — 중국어→한국어 번역 사전

중국 서버 화면의 중국어를 한국어로 바꿔 놓는 데 쓰라고 만든 사전입니다.

**파일은 내용 갈래로만 나뉩니다** — 오퍼, 아이템, 적, 작전, 생존연산, 통합전략, 스토리.
찾으시는 것이 어느 파일에 있는지는 이름만 보면 됩니다. 값은 한국어뿐입니다.

한 파일 안에 두 종류가 섞여 있고, **항목의 `x` 표시로 갈립니다.**

- **표시 없음 — 게임의 공식 한국어.** 한국 서버에 이미 나온 것의 중국어 원문과 공식
  한국어를 같은 id끼리 짝지은 것입니다. 번역이 아니라 대조라 손댄 곳이 없습니다.
- **`"x": 1` — 테라 아카이브의 비공식 번역.** 한국 서버에 아직 오지 않아 공식 한국어가
  없는 것이라, 정식 번역이 나오면 달라질 수 있습니다.

- 시작점: `https://files.terra-archive.net/assets/tl/manifest.json`
  — **앱에 박아 둘 주소는 이것 하나면 됩니다.** 나머지 파일 주소는 manifest 안에 들어
  있습니다 (`files[].url`). 주소를 직접 조합하지 마세요.
- 라이선스: **출처만 밝히면 재배포·상업적 이용까지 자유롭게 쓰셔도 됩니다.**
  미리 물어보실 것 없습니다. 자세한 것은 아래 **이용 조건**.

## 요청 방법

1. `manifest.json`을 받습니다.
2. `files[]`의 `hash`를 저장해 둔 값과 견줍니다.
3. 달라진 것만 그 항목의 `url`로 받아 덮어씁니다.

- **기기에 받아 두고 오프라인으로 쓰셔도 됩니다.**
- `manifest.json`은 **하루 한 번**이면 충분합니다. 나머지는 해시가 달라졌을 때만 받으세요.
- 사이트 화면(HTML)을 긁지 마세요. 필요한 것은 전부 여기 있습니다.
- `User-Agent`는 아무거나 괜찮습니다만 **`Python-urllib`은 막힙니다** (Cloudflare 봇 규칙).
  안드로이드 기본값(okhttp·Dalvik)은 그대로 통과합니다.

각 항목이 무엇인지와 `?v=`·`updated`의 뜻은 아래 **갱신 확인**에 있습니다.

전량 약 16.8 MB입니다. 한 파일이 하나의 콘텐츠에 대응하므로 필요한 것만 받으면 됩니다.

`ra.json`은 전부 비공식 번역입니다 — 한섭에 아직 안 나온 것이라 공식 한국어가
없습니다. `story.json`도 거의 전부 비공식입니다 — 화자 이름이나 「好。」 같은 짧은
대답처럼 **다른 데서 공식 한국어가 이미 있는 원문만** 공식을 썼습니다. 나머지 파일은
공식과 비공식이 섞여 있고 `x`로 갈립니다.

**`story.json`의 번역은 기계 번역 초벌입니다.** 인명·지명·호칭은 게임의 공식 한국어
표기에 맞춰 고쳤고, 조사와 문장부호도 바로잡았습니다. 그러나 문장 자체는 다듬지 않아
직역투이거나 어색한 곳이 많습니다. 대략의 뜻을 짚는 정도로 쓰세요. 다른 파일의 비공식
번역과 같은 `x` 표시를 달고 있지만 품질은 같지 않습니다.

주소는 언제나 `https://files.terra-archive.net/assets/tl/<파일 이름>` 입니다. 위 주소는 **눌러서 들여다보시라고** 적어 둔 것이고,
앱에서 **받을 때는 `manifest.json`의 `url`을 쓰세요** — 거기엔 해시가 `?v=`로 붙어 있어
중간 캐시가 옛 내용을 돌려주지 않습니다.

## 모양

키가 **중국어 원문 그대로**입니다 (공백·문장부호 포함 정확히 일치해야 합니다).
게임 데이터 ID(`char_xxx`·`rogue_3_relic_xxx` 같은 것)로는 찾을 수 없습니다 — 여기 담긴
것은 **화면에 보이는 글자**뿐입니다. OCR로 읽은 문자열을 그대로 키로 쓰시면 됩니다.

통합전략(`is.json`)만 갈래로 한 겹 싸여 있고, 나머지는 평평합니다.
테마 1~6은 한 파일에 함께 들어 있습니다. 갈래 이름은 다섯 가지뿐입니다:

| 키 | 담긴 것 |
|---|---|
| `collectibles` | 소장품·도구·캡슐·유물 |
| `nodes` | 노드 종류·구역·날씨·난이도 |
| `encounters` | 조우·방문객 |
| `endings` | 엔딩 |
| `battles` | 작전·적·분대·전투 기믹 |

```json
// is.json
{
 "collectibles": {
  "地形图": { "ko": "지형도" },
  "神音海螺": { "ko": "신탁의 소라" }
 },
 "battles": {
  "死囚之夜": { "ko": "사형수의 밤" }
 }
}
```

없는 갈래는 키 자체가 빠지므로, 읽을 때 다섯 개가 다 있다고 가정하지 마세요.

```json
// item.json
{
 "源石虫":    { "ko": "원석충" },
 "热腾腾大包": { "ko": "따끈따끈 왕만두", "x": 1 }
}
```

**`x: 1` 이 붙은 것만 비공식 번역**입니다. 없으면 게임의 공식 한국어입니다.

`story.json`의 키는 **대사 한 줄 전체**입니다. 게임에서 두 줄로 꺾여 나오는 대사는 키에도
줄바꿈(`\n`)이 들어 있으니, OCR이 줄마다 따로 읽었다면 이어 붙여서 찾으세요. 화자 이름·
선택지·장소 표시·편 제목도 같은 파일에 평평하게 들어 있습니다. 같은 원문이 장면마다
다르게 옮겨진 것(「是。」 같은 짧은 대답)은 가장 많이 쓰인 번역 하나만 남겼습니다.

## 갱신 확인

`manifest.json`의 생김새입니다. 갱신은 중국 서버 패치를 따라가므로 대개
**2~3주에 한 번**입니다.

```json
{
 "updated": "2026-09-17",
 "files": [
  { "file": "item.json",
    "url": "https://files.terra-archive.net/assets/tl/item.json?v=cc454255bbb7e330",
    "label": "아이템·재료 — 이름·설명·용도 — …",
    "hash": "cc454255bbb7e330" }
 ]
}
```

| 항목 | 쓰임 |
|---|---|
| `file` | 저장해 둘 때의 이름표. **해시를 여기에 걸어 두세요** — `url`은 갱신될 때마다 바뀝니다 |
| `url` | 바로 요청할 주소 |
| `label` | 받아 보기 전에 무엇인지 알려 줍니다 (고르는 화면을 만든다면 여기를 쓰세요) |
| `hash` | 바뀌었나 — 증분 판정은 이것 하나로 합니다 |

항목 수는 싣지 않습니다. 파일은 통째로 받으므로 미리 알아야 정할 일이 없고, 받고 나면
세면 되며, 내용이 온전한지는 `hash`가 더 정확하게 알려 줍니다.

위 해시는 예시입니다 — 실제 값은 받아 보신 manifest 를 쓰세요.

`url` 끝의 `?v=`는 그 파일의 해시입니다. **붙은 그대로 요청하세요** — 내용이 바뀌면
주소도 바뀌므로, 중간 캐시나 CDN이 옛 내용을 돌려주는 일이 없습니다. 떼고 요청해도
같은 파일이 오지만 최대 1분쯤 옛 내용일 수 있습니다.

바뀌는 빈도가 파일마다 다릅니다. **비공식 번역(`x`)은 중국 서버 패치마다 늘고**,
공식 쪽은 한국 서버 점검 때 늘어납니다. 통합전략은 거의 그대로입니다.
스토리는 새 스토리가 번역되면 늘고, 한국 서버에 나오면 빠집니다.
`op.json`이 전체의 절반입니다 — 오퍼 하나가 추가되면 이름·스킬·보이스·기록이 한꺼번에
들어오므로 한 덩어리로 두었습니다.

형식 버전 같은 것은 두지 않았습니다. 대신 **형식을 깨야 할 일이 생기면 여기를 고치지
않고 주소를 새로 팝니다** — 이미 쓰고 계신 앱은 지금 주소에서 그대로 돌아갑니다.
항목이 늘어나는 정도는 깨는 변경이 아니니, 모르는 항목은 무시하도록 만들어 두세요.

`updated`는 **파일을 만든 날짜**지 내용이 바뀐 날짜가 아닙니다 — 내용이 그대로여도
올라갑니다. **갱신 판정에는 `hash`만 보세요.**

## 여기 없는 것

- **한국 서버에 이미 나온 스토리** — 없습니다. `story.json`은 한국 서버에 아직 없는
  스토리만 담습니다. 이미 나온 스토리도 중국어 원문과 공식 한국어가 줄 단위로 짝이
  맞지만(실측으로 확인했습니다) 1,900편 남짓, 어림잡아 50 MB라 아직 싣지 않았습니다.
  그래서 **한국 서버에 나온 스토리는 `story.json`에서 빠집니다.**

## 이용 조건

**조건은 출처 표시 하나뿐입니다.** 재배포도, 상업적 이용도, 고쳐서 쓰는 것도 따로
허락받을 필요 없이 하셔도 됩니다. 표준 라이선스로 말하면 **CC BY 4.0**에 해당합니다.

1. 출처를 **테라 아카이브(terra-archive.net)**로 밝혀 주세요. 앱이라면 정보·설정 화면
   한 줄이면 충분합니다. 그대로 쓰셔도 되는 문구:

   ```
   번역 출처: 테라 아카이브 (terra-archive.net) · 비공식 번역
   ```

부탁 (조건은 아닙니다):

- **비공식 번역**임을 함께 밝혀 주시면 좋겠습니다 — 공식 한국어 표기가 아니라서,
  쓰시는 분이 게임 안 표기와 다르다고 혼란스러워하는 일을 줄일 수 있습니다.
- 스토리를 쓰신다면 **기계 번역**이라는 것도 같이 밝혀 주세요.
- 고쳐서 쓰셨다면 고쳤다는 것도 적어 주세요.

밝혀 둘 것:

- 여기서 드리는 것은 **번역문**뿐입니다. 원문(중국어)과 게임 내 명칭의 권리는
  Hypergryph·Yostar에 있고, 그 권리는 저희가 넘겨 드릴 수 있는 것이 아닙니다.
- 특히 `story.json`은 원작 스토리를 옮긴 것이라 **원작의 권리 아래 있습니다.** 위의
  "출처만 밝히면 자유"는 저희가 보탠 몫(번역)에 대한 이야기이고, 원작 권리자의 허락까지
  대신할 수는 없습니다.
- 번역은 **있는 그대로** 드립니다. 정확성을 보증하지 않고, 쓰다 생긴 문제에 책임지지
  않습니다. 정식 한국어가 나오면 그쪽이 정확합니다.

궁금한 것이 있으면: contact@terra-archive.net (허락을 받으려고 메일 주실 것은 없습니다)
