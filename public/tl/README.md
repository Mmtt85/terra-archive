# 테라 아카이브 — 중국어→한국어 번역 사전

중국 서버 선행 콘텐츠를 중심으로 한 **비공식 번역** 모음입니다. 한국 서버에 아직 오지
않아 공식 한국어가 없는 텍스트를 테라 아카이브가 옮긴 것이라, 정식 번역이 나오면
달라질 수 있습니다.

- 시작점: `https://files.terra-archive.net/assets/tl/manifest.json`
  — **앱에 박아 둘 주소는 이것 하나면 됩니다.** 나머지 파일 주소는 manifest 안에 들어
  있습니다 (`files[].url`). 주소를 직접 조합하지 마세요.
- 라이선스: 아래 **이용 조건** 참조. 자동 승인이 아니라 **사전 협의 대상**입니다.

## 파일

| 파일 | 내용 | 항목 |
|---|---|---:|
| `op-fut.json` | 오퍼레이터·재료 — **아직 한국 서버에 없는 것** | 351 |
| `op-past.json` | 오퍼레이터·재료 — 한국 서버 출시로 공식 번역이 덮은 옛 항목 | 2,451 |
| `ra.json` | 생존연산 (중국 서버 선행) | 1,157 |
| `is1.json` … `is6.json` | 통합전략 1~6 (6은 중국 서버 선행) | 726~1,519 |
| `is-common.json` | 통합전략 공통 — 조우 안내·판정 문구 | 298 |
| `manifest.json` | 위 목록 + 파일별 해시 | — |

전량 약 3.2 MB입니다. 한 파일이 하나의 콘텐츠에 대응하므로 필요한 것만 받으면 됩니다.

## 모양

키가 **중국어 원문 그대로**입니다 (공백·문장부호 포함 정확히 일치해야 합니다).

통합전략은 갈래로 한 겹 싸여 있습니다 — `소장품` · `노드` · `조우` · `엔딩` · `전투`.

```json
// is3.json
{
 "소장품": {
  "地形图": { "ko": "지형도" },
  "神音海螺": { "ko": "신탁의 소라" }
 },
 "전투": {
  "死囚之夜": { "ko": "사형수의 밤" }
 }
}
```

오퍼·재료·생존연산은 갈래 없이 평평합니다.

```json
// op-fut.json
{
 "进驻发电站时，无人机充能速度+15%…": {
  "ko": "발전소에 배치 시, 드론 충전 속도 +15%…",
  "en": "When assigned to a Power Plant…",
  "ja": "発電所に配置時、ドローンの充電速度+15%…"
 }
}
```

`en`·`ja`는 없을 수 있습니다 (한국어만 있는 출처가 있습니다).

## 갱신 확인

`manifest.json`에 파일마다 `hash`와 **바로 요청할 수 있는 `url`** 이 있습니다.
저장해 둔 해시와 다른 파일만 그 `url`로 다시 받으면 됩니다. 갱신은 중국 서버 패치를
따라가므로 대개 **2~3주에 한 번**입니다.

```json
{
 "v": 4,
 "updated": "2026-09-17",
 "base": "https://files.terra-archive.net/assets/tl",
 "total": 10478,
 "files": [
  { "file": "op-fut.json",
    "url": "https://files.terra-archive.net/assets/tl/op-fut.json?v=b31eeb9f964e6e50",
    "label": "…", "n": 351, "hash": "b31eeb9f964e6e50" },
  { "file": "is3.json",
    "url": "https://files.terra-archive.net/assets/tl/is3.json?v=d5bfd1d1d5696076",
    "label": "…", "n": 991, "hash": "d5bfd1d1d5696076",
    "groups": { "소장품": 310, "노드": 20, "조우": 267, "엔딩": 21, "전투": 373 } }
 ]
}
```

`url` 끝의 `?v=`는 그 파일의 해시입니다. **붙은 그대로 요청하세요** — 내용이 바뀌면
주소도 바뀌므로, 중간 캐시나 CDN이 옛 내용을 돌려주는 일이 없습니다. 떼고 요청해도
같은 파일이 오지만 최대 1분쯤 옛 내용일 수 있습니다.

`base`는 주소를 직접 조합하고 싶을 때 쓰라고 둔 것입니다. 보통은 `url`을 그대로 쓰면
됩니다.

바뀌는 빈도가 파일마다 다릅니다. **`op-fut.json`이 가장 자주 늘고**, `op-past.json`과
통합전략 1~5는 거의 그대로입니다.

`v`가 모르는 값으로 바뀌면 형식이 달라진 것이니 전량을 다시 받으세요.

`updated`는 **파일을 만든 날짜**지 내용이 바뀐 날짜가 아닙니다 — 내용이 그대로여도
올라갑니다. **갱신 판정에는 `hash`만 보세요.**

## 요청 예의

- `manifest.json`은 **하루 한 번**이면 충분합니다. 나머지는 해시가 달라졌을 때만 받으세요.
- 사이트 화면(HTML)을 긁지 마세요. 필요한 것은 전부 여기 있습니다.

## 여기 없는 것

- **오퍼레이터·아이템·적·작전의 한국 서버 공식 텍스트** — 한섭에 이미 나온 것은 게임
  데이터에 공식 한국어가 있고 **그쪽이 여기 번역문보다 정확합니다.** 게임에서 직접
  얻으세요. `op-past.json`은 참고용 옛 기록입니다.
- **적·작전 정보** — 위와 같은 이유로 번역 대상이 아니었습니다. 여기 있는 적·작전은
  통합전략 것(`is*.json`의 `전투`)뿐입니다.
- **스토리 본문·명칭** — 스토리 번역은 한국어를 키로 삼아 영어·일본어로 옮긴 것이라
  중국어 원문이 없습니다. 중국어 화면에서 찾을 수 있는 형태가 아닙니다.
- **통합전략 조우 분기 전문** — 담은 것은 이름·제목·설명까지입니다.
