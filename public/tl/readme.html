테라 아카이브 — 중국어→한국어 번역 사전

중국 서버 선행 콘텐츠를 중심으로 한 비공식 번역 모음입니다. 한국 서버에 아직 오지 않아 공식 한국어가 없는 텍스트를 테라 아카이브가 옮긴 것이라, 정식 번역이 나오면 달라질 수 있습니다.

  • 시작점: https://files.terra-archive.net/assets/tl/manifest.json — 앱에 박아 둘 주소는 이것 하나면 됩니다. 나머지 파일 주소는 manifest 안에 들어 있습니다 (files[].url). 주소를 직접 조합하지 마세요.
  • 라이선스: 출처만 밝히면 재배포·상업적 이용까지 자유롭게 쓰셔도 됩니다. 미리 물어보실 것 없습니다. 자세한 것은 아래 이용 조건.

요청 방법

  1. manifest.json을 받습니다.
  2. files[]의 hash를 저장해 둔 값과 견줍니다.
  3. 달라진 것만 그 항목의 url로 받아 덮어씁니다.
  • manifest.json은 하루 한 번이면 충분합니다. 나머지는 해시가 달라졌을 때만 받으세요.
  • 사이트 화면(HTML)을 긁지 마세요. 필요한 것은 전부 여기 있습니다.

각 항목이 무엇인지와 ?v=·updated의 뜻은 아래 갱신 확인에 있습니다.

파일

파일내용항목
manifest.json아래 목록 + 파일별 해시·주소—
op-fut.json오퍼레이터·재료 — 아직 한국 서버에 없는 것351
op-past.json오퍼레이터·재료 — 한국 서버 출시로 공식 번역이 덮은 옛 항목2,451

전량 약 3.2 MB입니다. 한 파일이 하나의 콘텐츠에 대응하므로 필요한 것만 받으면 됩니다.

주소는 언제나 https://files.terra-archive.net/assets/tl/<파일 이름> 입니다. 위 주소는 눌러서 들여다보시라고 적어 둔 것이고, 앱에서 받을 때는 manifest.json의 url을 쓰세요 — 거기엔 해시가 ?v=로 붙어 있어 중간 캐시가 옛 내용을 돌려주지 않습니다.

모양

키가 중국어 원문 그대로입니다 (공백·문장부호 포함 정확히 일치해야 합니다).

통합전략은 갈래로 한 겹 싸여 있습니다. 갈래 이름은 다섯 가지뿐입니다:

키담긴 것
collectibles소장품·도구·캡슐·유물
nodes노드 종류·구역·날씨·난이도
encounters조우·방문객
endings엔딩
battles작전·적·분대·전투 기믹
// is3.json
{
 "collectibles": {
  "地形图": { "ko": "지형도" },
  "神音海螺": { "ko": "신탁의 소라" }
 },
 "battles": {
  "死囚之夜": { "ko": "사형수의 밤" }
 }
}

is-common.json은 encounters 하나만 들고 있습니다. 없는 갈래는 키 자체가 빠지므로, 읽을 때 다섯 개가 다 있다고 가정하지 마세요.

오퍼·재료·생존연산은 갈래 없이 평평합니다.

// op-fut.json
{
 "进驻发电站时，无人机充能速度+15%…": {
  "ko": "발전소에 배치 시, 드론 충전 속도 +15%…",
  "en": "When assigned to a Power Plant…",
  "ja": "発電所に配置時、ドローンの充電速度+15%…"
 }
}

en·ja는 없을 수 있습니다 (한국어만 있는 출처가 있습니다).

갱신 확인

manifest.json의 생김새입니다. 갱신은 중국 서버 패치를 따라가므로 대개 2~3주에 한 번입니다.

{
 "updated": "2026-09-17",
 "files": [
  { "file": "op-fut.json",
    "url": "https://files.terra-archive.net/assets/tl/op-fut.json?v=b31eeb9f964e6e50",
    "label": "오퍼레이터·재료 — 아직 한국 서버에 없는 것",
    "hash": "b31eeb9f964e6e50" }
 ]
}
항목쓰임
file저장해 둘 때의 이름표. 해시를 여기에 걸어 두세요 — url은 갱신될 때마다 바뀝니다
url바로 요청할 주소
label받아 보기 전에 무엇인지 알려 줍니다 (고르는 화면을 만든다면 여기를 쓰세요)
hash바뀌었나 — 증분 판정은 이것 하나로 합니다

항목 수는 싣지 않습니다. 파일은 통째로 받으므로 미리 알아야 정할 일이 없고, 받고 나면 세면 되며, 내용이 온전한지는 hash가 더 정확하게 알려 줍니다.

url 끝의 ?v=는 그 파일의 해시입니다. 붙은 그대로 요청하세요 — 내용이 바뀌면 주소도 바뀌므로, 중간 캐시나 CDN이 옛 내용을 돌려주는 일이 없습니다. 떼고 요청해도 같은 파일이 오지만 최대 1분쯤 옛 내용일 수 있습니다.

바뀌는 빈도가 파일마다 다릅니다. op-fut.json이 가장 자주 늘고, op-past.json과 통합전략 1~5는 거의 그대로입니다.

형식 버전 같은 것은 두지 않았습니다. 대신 형식을 깨야 할 일이 생기면 여기를 고치지 않고 주소를 새로 팝니다 — 이미 쓰고 계신 앱은 지금 주소에서 그대로 돌아갑니다. 항목이 늘어나는 정도는 깨는 변경이 아니니, 모르는 항목은 무시하도록 만들어 두세요.

updated는 파일을 만든 날짜지 내용이 바뀐 날짜가 아닙니다 — 내용이 그대로여도 올라갑니다. 갱신 판정에는 hash만 보세요.

여기 없는 것

  • 오퍼레이터·아이템·적·작전의 한국 서버 공식 텍스트 — 한섭에 이미 나온 것은 게임 데이터에 공식 한국어가 있고 그쪽이 여기 번역문보다 정확합니다. 게임에서 직접 얻으세요. op-past.json은 참고용 옛 기록입니다.
  • 적·작전 정보 — 위와 같은 이유로 번역 대상이 아니었습니다. 여기 있는 적·작전은 통합전략 것(is*.json의 전투)뿐입니다.
  • 스토리 본문·명칭 — 스토리 번역은 한국어를 키로 삼아 영어·일본어로 옮긴 것이라 중국어 원문이 없습니다. 중국어 화면에서 찾을 수 있는 형태가 아닙니다.
  • 통합전략 조우 분기 전문 — 담은 것은 이름·제목·설명까지입니다.
