# 테라 아카이브 디자인 시스템

> 이 폴더는 디자인 시스템 Artifact(https://claude.ai/artifact/RVm5mCb7xq5L3JQpWiusJx — 작성 계정 전용)의 **저장소 사본**이다.
> 어느 계정·세션이든 이 폴더를 읽으면 된다. 색·반경·그림자·글자 규칙을 바꾸면 `app/globals.css` 맨 위 토큰과
> 이 폴더(`tokens.json`·이 README)를 함께 고친다. 정본 순서: **`app/globals.css` 실제 값 > 이 폴더 > Artifact**.
>
> - `tokens.json` — 색(라이트·다크·통합전략 주제 6개, 8테마)·글자·반경·그림자·자간 토큰과 쓰임새
> - `components/*.md` — 공용 단추·입력·칩·브랜드 마크·통합전략 판 사용 규칙
> - `components/bundle.css` — 위 컴포넌트를 토큰만으로 옮겨 그린 참고용 스타일 (사이트가 불러오지 않는다)
> - 브랜드 마크 그림: `public/favicon-180.png` · 본문 서체 파일: `public/fonts/suite/SUITE-Variable.woff2`

명일방주 한국 서버 팬사이트의 화면 규칙이다. 인게임 UI처럼 각진 판과 가는 선, 차가운 회색 바탕에 잉크 글자, 강조는 라임 한 가지. 장식보다 정보가 먼저이고, 값은 아래 토큰 안에서만 고른다 — 낱개로는 그럴듯한 0.5px·새 빨강·새 금색이 모이면 "제각각"으로 읽힌다.

## 콘텐츠

- **세 언어.** 한국어(`/`)가 정본, 영어(`/en`)·일본어(`/ja`)는 같은 키로 번역한다. 한국어 문구를 바꾸면 번역 사전의 같은 키도 바꾼다.
- **짧은 명사형 라벨.** 버튼은 "전체 자동편성", "공유", "새 제안"처럼 동사 없이. 설명은 존댓말 평서문.
- **게임 용어는 한섭 표기 그대로.** 오퍼레이터, 공개모집(공채), 통합전략, 위수 협의, 작전. 중국 서버 선행 정보는 "미래시"·"미실장"으로 구분해 표시한다.
- **이모지를 장식으로 쓰지 않는다.** 기호는 글리프로: 드롭다운 `▾`, 로딩 `⋯`, 확인 `✓`, 성급 `★`.

## 색

- 바탕 회색은 **네 단계뿐**: `paper`(본문) → `white`(카드·버튼 판) → `bg-panel`(서브 표면) → `bg-soft`(눌린 칸·칩·입력), 그 위 호버는 `bg-press`. `bg-faint`·`bg-panel2`·`bg-soft2` 는 옛 이름이라 새로 쓰지 않는다. 순백·순흑은 쓰지 않는다.
- 본문 바닥에는 `grid-line` 40px 격자가 아주 옅게 깔린다 (작전 도면의 칸).
- 글자는 `ink` → `ink2` → `ink3` → `muted` 순으로 옅어진다. `muted` 보다 옅은 글자는 만들지 않는다 (라이트 4.7:1).
- 테두리는 3단: 기본 `line`, 호버 `border-hover`, 강조·포커스 `border-strong`. 어두운 칩 위 테두리만 `chip-line`.
- **라임(`lime`)은 강조 전용.** 바탕에 넓게 깔지 않는다. 라임 채움 위 글자는 `on-lime`.
- **밝은 바탕 위 라임은 그대로 쓰지 않는다** — 종이 위 1.5:1 이라 안 보인다. 글자면 `lime-ink`, 테두리·윤곽선·포커스 링·밑줄·가는 표식 막대면 `lime-line`. 다크·통합전략에선 둘 다 라임과 같다. `lime` 그대로는 어두운 칩 위 글자·라임 채움에만.
- 의미색은 셋 중에서 고른다: `gold`(이벤트·확정), `danger`(삭제·오류·경고), `crimson`(작전·시뮬 — 오류가 아니라 정체성). 상태 글자는 `ok`·`danger`·`gold-ink`·`blue-ink`. `bad` 는 `danger`, `amber-ink`·`star-ink` 는 `gold-ink` 의 옛 이름이다.
- 파스텔 칩은 바탕+잉크 짝으로만: `tint-lime`+`tint-lime-ink`, `tint-warm`+`tint-warm-ink`, `tint-warm2`+`tint-warm2-ink`, `tint-gold`+`gold-ink`, `tint-red`+`danger`.
- 채도는 낮게. 카드 장식은 근거가 없으면 뺀다.

## 버튼 — 역할은 넷뿐

값을 직접 적지 말고 역할을 고른다.

| 역할 | 토큰 | 쓰는 곳 |
|---|---|---|
| 기본 | `btn-bg` · `btn-line` · `btn-ink` | 대부분의 버튼 |
| 호버 | `btn-bg-hover` · `btn-line-hover` · `btn-ink-hover` | 바탕이 한 단계 눌리고 테두리·글자가 진해진다 |
| 선택됨 | `btn-on-bg` · `btn-on-ink` | 명암 반전 — 라이트는 어두운 알약, 다크는 밝은 알약 |
| 강조 | `btn-pri-bg` · `btn-pri-line` · `btn-pri-ink`, 호버 `btn-pri-bg-hover` | 화면당 한둘인 주요 행동. 칩 + 라임 글자, 호버는 라임 채움 |

메뉴 행처럼 평소 테두리가 없는 것의 호버는 `btn-ghost-hover`. 터치 기기에선 호버 칠을 끈다 — 눌어붙는다.

공용 단추 결은 세 갈래다: **드롭다운·실행 단추**는 `soft-fill` 바탕·테두리 없음, 호버 때 `tab-line` 밑줄이 왼쪽에서 자란다. **탭 단추**는 바탕 없이 밑줄만. **입력란**은 `field-fill` 바탕에 평소 `field-rule` 1px 밑줄, 포커스면 `field-fill-focus` + `tab-line` 2px 밑줄. 다크에선 선택된 밑줄·글자에 라임 빛 번짐이 얹힌다(라이트에선 뿌옇게 보여 안 쓴다).

## 글꼴

- 본문은 `sans`: **SUITE Variable**(획 끝이 살짝 둥근 서체) → 없는 글자는 **Pretendard Variable** 이 받는다. 이 순서를 바꾸지 않는다.
- 숫자·영문 라벨은 `mono`(Geist Mono). 한글은 본문 서체로 떨어지게 짜여 있다 — `monospace` 를 직접 쓰지 않는다.
- 일본어 페이지는 `ja`(Meiryo 우선).
- 크기는 9 · 10 · 11 · 12 · 13 · 14 · 16 · 18 · 20 · 22 · 26 · 30px 에서만. 본문·UI 는 10~14, 제목은 16 위. 10.5 같은 반값 금지. 장식 숫자(34·64·92·190)와 미니 배지(8)만 예외.
- 굵기는 세 단계: 600 본문 볼드(카드 이름·칩·표 숫자), 700 소제목, 800 큰 제목. `<b>`·`<strong>` 도 600.
- 행간: 1(한 줄·아이콘) · 1.25(제목) · 1.45(UI 여러 줄) · 1.6(본문) · 1.75(긴 글). 자간은 '자간' 묶음의 여덟 단계.

## 모양

- **각진 판.** 반경은 1~4px: `r-xs` 1 표식, `r-sm` 2 버튼·입력·배지, `r-md` 3 카드·패널·드롭다운, `r-lg` 4 모달·히어로. 알약 모양은 걷었다(`r-pill` 도 3px). 원형만 50%.
- 그림자는 세 단계: `sh-1` 아래 1px 선(살짝 든 것), `sh-2` 아래로 좁게 떨어지는 그림자(떠 있는 것), `sh-3` 넓게 퍼지는 그림자(모달). 카드는 따로 `sh-card`, 올리면 `sh-card-hover` 로 짙어지며 2px 떠오른다. 위계는 그림자보다 테두리가 먼저 말한다.
- 움직임은 transform 으로만. 크기를 레이아웃(grid 행·height)으로 애니메이션하면 그림이 정수 픽셀로 계단처럼 끊긴다 — 오퍼 카드 펼침은 패널 translateY + 얼굴 scale(밑변 기준).
- 헤더는 불투명 `header-bg` 판(흐림 없음) + 아래 `line` 1px, 데스크톱에선 왼쪽 아래에 72×2px `lime-line` 표식. 페이지 제목 아래에도 48×2px 같은 표식.
- 글로우·그라데이션은 걷었다. 다크에서만 선택된 밑줄에 라임 빛 번짐이 남는다.
- 움직임은 짧게: 밑줄·색 전환 0.2~0.25s. 스크롤은 미끄러지지 않고 즉시 점프한다.
- 다크모드는 `html.dark` 클래스로 토큰을 통째로 갈아 끼운다. 통합전략 화면은 라이트에서도 항상 다크 (아래 '통합전략 테마').

## 통합전략 테마

통합전략(IS) 가이드 화면은 라이트·다크 설정과 상관없이 **항상 다크**다. 이 화면에선 사이트 토큰이 '통합전략' 테마로 바뀌고(값은 다크와 같다 — 헤더·모달·칩만 허옇게 뜨는 '반쪽 다크'를 막는다), 화면 자체는 `rg*` 색으로 칠한다.

- 바탕 `rgbg`, 카드 `rgcard`, 모달 `rgmodal`, 깊은 칸 `rgdeep`, 고른 칸 `rgsel`.
- 테두리 `rgline`, 모달 테두리 `rgmodalline`.
- 글자 `rgink` → `rgtext2` → `rgmut`. 제목·등급은 `rggold`, 강조는 `rgcrim`, 상승 수치는 `rgupbg` 위 `rgup`.
- 통합전략 화면의 단추·입력란은 공용 결을 따르지 않고 제 모양을 쓴다.
- 주제(시즌)마다 `rg*` 값만 갈아 끼운다. 주제 여섯이 각각 테마로 들어 있다(`rogue` 팬텀 · `rogue2` 미즈키 · `rogue3` 은빛 서리 · `rogue4` 살카즈 · `rogue5` 계원 · `rogue6` 블랙플로우). 라이트·다크 테마의 `rg*` 는 첫 주제 값이다.

## 브랜드 마크

`public/favicon-180.png` — 어두운 `chip` 판 위 캐릭터 초상을 위쪽 기준으로 채우고, 오른쪽 아래 모서리를 28% 깎은 다각형(`polygon(0 0, 100% 0, 100% 72%, 72% 100%, 0 100%)`)으로 자른다. 헤더에선 39px, 옆에 사이트 이름(`heading` 800, 자간 `ls-n05`)과 고정폭 부제(`mono-label`, `muted`).

## 아이콘

전용 아이콘 세트는 없다. 유니코드 글리프(`▾ ⋯ ✓ ★ ✕`)와 게임 원본 이미지(재료·직군·오퍼 초상)를 쓴다. 단색 SVG 아이콘을 새로 만들지 않는다.
