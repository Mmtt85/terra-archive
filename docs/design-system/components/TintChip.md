# 파스텔 칩
상태·분류를 표시하는 파스텔 칩 — 바탕과 전용 잉크를 짝으로 쓴다.

- 사용: `<span class="ta-chip lime">미실장</span>`. 종류: `lime` `warm` `warm2` `gold` `red` `cream`.
- 바탕과 글자는 반드시 짝(`tint-lime`+`tint-lime-ink` …). 다크에선 어두운 동계열 틴트로 뒤집힌다.
- 반경 `r-sm`, 글자 11px 600.
- 금색 칩(`gold`)은 라이트에서 약 3:1 — 짧은 굵은 라벨에만.
- 색만으로 뜻을 전하지 않는다. 칩 안 낱말이 뜻을 말한다.
