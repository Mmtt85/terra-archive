# 버튼
네 역할(기본·선택됨·강조·위험 글자) 중 하나를 고르는 사이트 기본 버튼이다.

- 사용: `<button class="ta-btn">`, 선택됨은 `.on`, 주요 행동은 `.pri`, 삭제는 `.danger`.
- 강조(`.pri`)는 화면당 한둘. 여러 개면 기본으로 내린다.
- 선택됨은 명암 반전(`btn-on-*`)으로 표시한다 — 라임으로 채우지 않는다. 라임은 강조 전용.
- 선택된 버튼 안의 보조 숫자는 `<small>` (`btn-on-dim`).
- 반경 `r-sm`, 글자 `ui`(12px 600). 값을 직접 적지 말 것.
- 소비자가 줄 것: 라벨 텍스트, 선택 상태 클래스, 클릭 처리.

app/globals.css 의 `--btn-*` 규칙을 손으로 옮겨 그린 정적 재현이다.
