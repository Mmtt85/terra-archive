# 통합전략 판
통합전략(IS) 가이드 화면의 카드 — 사이트 토큰 대신 `rg*` 색만 쓰는 어두운 극장풍 판이다.

- 통합전략 화면은 라이트·다크 설정과 상관없이 **항상 다크**다. 이 화면에선 사이트 토큰도 '통합전략' 테마(=다크 값)로 바뀐다.
- 판 `rgcard`, 테두리 `rgline`, 반경 `r-md`. 제목은 `rggold`, 본문 `rgink`, 보조 `rgtext2`, 캡션 `rgmut`.
- 고른 태그는 `rgsel` 바탕 + `rgcrim` 테두리. 상승 수치는 `rgupbg` 위 `rgup`.
- 주제(시즌)마다 `rg*` 값만 갈아 끼운다 — 규칙은 그대로. 주제 여섯은 각각 테마(`rogue`~`rogue6`)로 들어 있고, 값 표는 문서의 '통합전략 테마' 절.
- 소비자가 줄 것: 제목, 설명, 태그 목록, 수치.
