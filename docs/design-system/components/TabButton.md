# 탭 단추
화면 안 보기를 바꾸는 탭 — 바탕 없이 밑줄만으로 선택을 표시한다.

- 사용: `<div class="ta-tabs"><button class="ta-tab on">…</button>…</div>`.
- 평소 글자 `ink3`, 호버·선택 `ink`. 밑줄은 안쪽 10px, `tab-line` 에서 투명으로 사라지는 그라데이션.
- 선택된 탭은 밑줄이 고정된다. 다크에서만 글자에 라임 빛 번짐.
- 상자 테두리·바탕을 주지 않는다. 선택 칩·토글은 탭이 아니다 — Button 을 쓴다.
- 소비자가 줄 것: 탭 라벨, 선택 상태.
