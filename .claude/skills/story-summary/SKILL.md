# AI 스토리 요약 집필

`app/data/story-summaries.json`에 이벤트 요약을 추가한다. 이벤트 목록·썸네일은
`scripts/build-story.py`가 자동 생성하지만, **요약 본문은 AI(Claude)가 스토리 스크립트
전문을 정독하고 직접 집필한다** — 시놉시스 짜깁기 금지, 반드시 원문을 읽을 것.
상세 규칙: [docs/PROJECT-GUIDE.md](../../../docs/PROJECT-GUIDE.md) §6.6.

## 절차

1. **대상 확인**: `app/data/stories.json`에서 이벤트 id 확인 (없으면
   `python3 scripts/build-story.py` 먼저 — 신규 이벤트 목록·썸네일 갱신).
2. **스크립트 다운로드**: 클뜯 레포 `kr/gamedata/excel/story_review_table.json`의
   해당 이벤트 `infoUnlockDatas[].storyTxt` 경로대로
   `kr/gamedata/story/<storyTxt>.txt`를 스크래치 폴더에 받는다 (에피소드 15~25개).
   ⚠ 일부 구 이벤트(예: act24side)는 kr 폴더에 스크립트가 없다 — cn밖에 없으면
   중국어 원문 기반 집필이 되므로 사용자에게 먼저 알릴 것.
3. **대사 추출**: `[name="X"] 대사` / 태그 없는 줄(나레이션) / `[Image(image=...)]`(컷씬
   위치)만 뽑아 플레인 텍스트로 변환 후 **storySort 순서대로 전부 정독**한다.
   에피소드마다 노트(인물·사건·명대사·개그 포인트·CG 위치)를 남겨가며 읽는다.
4. **컷씬 수집**: `python3 scripts/build-story.py --cuts <eventId>` →
   `public/story/cut/<name>.webp`. 요약에 쓸 장면을 고른다.
4-1. **인물 카드 이미지 = 오퍼레이터 얼굴 섬네일로 통일 (사용자 확정 2026-07, 규칙 반전).**
   **스탠딩 CG를 붙이지 않는다.** chars 배열의 각 인물에 `img`를 **넣지 말고** `op`(operators.json
   char id)만 채우면, 레일이 자동으로 백과사전 얼굴 아바타(`/avatars/<op>.webp`)를 정사각으로
   띄운다. 이렇게 해야 모든 이벤트가 동일한 얼굴 섬네일로 통일된다 (이전엔 스탠딩 CG를 썼으나
   이벤트마다 때깔이 달라 사용자가 얼굴 섬네일로 일원화 지시). 플레이어블이 아닌 순수 NPC는
   op가 없으니 이미지 없는 텍스트 카드가 된다(오퍼가 아니므로 얼굴이 없음 — 정상).
   ⚠ `--chars` 스탠딩 CG 다운로드 단계는 더 이상 쓰지 않는다. 본문 장식 삽화(deco 블록)로
   보스/조각상 등을 넣을 때만 `public/story/char/`에 개별 이미지를 둘 수 있다.
   ⚠ 정체가 반전인 인물(예: act48side 이타코스의 부친)은 chars에 넣지 않는다.
5. **집필**: story-summaries.json에 이벤트 id 키로 추가.
   **문체·구조·컷씬 배치·감정선 설계는 [WRITING-GUIDE.md](WRITING-GUIDE.md)를 그대로
   따른다** (사용자 승인 방법론 — 반드시 먼저 읽을 것).
6. **인물 생사 대조 패스 (필수)**: 집필 후 원문만 다시 보고, 요약에 등장하는 모든
   인물의 생사·거취가 원문과 일치하는지 대조한다 (WRITING-GUIDE §7-1). **원문에 없는
   후일담·근황 창작은 삭제**. 죽은 인물을 살려두거나 산 인물을 죽이는 환각이 가장 흔한
   오류다 — 이 패스를 건너뛰지 않는다.

## 집필 규칙 요약 (상세: WRITING-GUIDE.md)

- **분량 5,500~9,000자** (본문+캡션 합산, 1만 자 미만 필수. 파이썬으로 실측).
- **구어체 해요체 + 한 문단 1~3문장** — 줄바꿈 자주. 개그 구간과 감정 구간의 문체를
  다르게 (감정 클라이맥스에는 농담 금지).
- **결말 포함 전체 스포일러** (UI가 스포일러 경고를 자동 표시).
- **컷씬은 원문 [Image] 태그가 붙은 장면을 서술하는 문단 옆에 배치**, 캡션 필수.
- **한국어로 집필하되 발행은 3개 언어** — 집필이 끝나면 번역 파이프라인까지 돌린다
  (`story-i18n-setup.py` → 서브에이전트 번역 → `story-i18n-merge.py`, scripts/README §6.1).
  번역이 없는 이벤트는 EN/JA에서 한국어로 폴백되고 "한국어로만 제공" 안내가 뜬다.
  이미 발행된 요약을 고쳤다면 `story-i18n-backport.py`를 먼저 돌릴 것 — 안 그러면
  다음 merge가 그 수정을 옛 번역으로 덮는다.
- 명대사는 quote 블록으로(리프레인·티키타카·주제 문장만). 과장·창작 금지.

## JSON 형식

```jsonc
"act48side": {
  "tagline": "한 줄 소개 (목록·상세 상단에 노출)",
  "chars": [  // 인물 카드 — img 넣지 말 것. op만 있으면 얼굴 아바타 자동, 없으면 텍스트 카드
    { "name": "티티", "desc": "스포일러 없는 한 줄",
      "alias": ["메제티케티"], "op": "char_4056_titi" }
  ],
  "terms": [  // 용어 사전 — 리라·지명·제도처럼 처음 보면 모를 고유명사
    { "name": "리라", "desc": "한두 문장 설명 (뒤 내용 스포일러 금지)", "alias": ["별칭"] }
  ],
  "blocks": [
    { "t": "h",     "x": "챕터 제목" },
    { "t": "p",     "x": "본문 문단 — **굵게** 지원(rich)" },
    { "t": "img",   "src": "/story/cut/69_i01.webp", "cap": "캡션(선택)" },
    { "t": "quote", "who": "화자", "x": "명대사" }
  ]
}
```

chars·terms는 **본문 점선 밑줄 + 팝오버**에 쓰인다 (2026-07-25에 옛 오른쪽 레일 대체).
본문에 name이나 alias가 나오면 그 단어에 점선 밑줄이 붙고, 데스크탑은 마우스오버(커서 위쪽에
카드), 모바일은 탭(뒤로가기 아래 자리)으로 설명이 뜬다. 클릭하면 고정되고 바깥을 클릭하면 닫힌다.
그래서 desc는 반드시 그 시점 기준 스포일러가 없어야 하고, 정체가 반전인 인물·용어는 아예 넣지 않는다.
**요약 데이터(chars/terms)만 넣으면 공용 `StoryDetail` 컴포넌트가 자동으로 처리한다.**

⚠ **alias는 '그것을 부르는 다른 이름'만** (전수조사 후 37건 삭제, 2026-07-25):
- ✅ 본명·이격명·통칭·음차: 첸 ← 진휘결 / 총웨 ← 숴 / 마가렛 ← 니어 / 티티 ← 메제티케티
- ❌ **관련 개념**을 넣지 말 것 — 밑줄이 엉뚱한 카드로 연결된다:
  우르수스 ← 디에티 그라이퍼부르크(황실), 계원 ← 진무식(그곳에서 열리는 의식),
  사세대 ← 지촉인(그 조직의 사람), 광석병 ← 감염자·오리지늄, 용문 ← 용문근위국
- ❌ **일반 명사**도 금지 (본문 전체가 밑줄 범벅이 된다): 마을, 코어, 소대, 박사, 헌병
- ❌ 같은 편의 **다른 엔티티 이름**을 별칭으로 쓰지 말 것 (돌리 ← 쪼꼬미양처럼 충돌)
⚠ CSS 미디어쿼리는 `width>1180px` 같은 신문법 금지 — 빌드가 `@media not all…`로
컴파일해 안 먹는 사례 있음. min-width/max-width만 쓸 것.

**op 연결 규칙**: 인물이 플레이어블 오퍼레이터면 `op`에 operators.json의 char id를 넣는다
— 카드 클릭 시 오퍼 상세 모달이 열린다. **스토리 본명과 오퍼명이 다르면 반드시 둘 다
표기**: desc 끝에 "오퍼레이터 <오퍼명>"을 붙인다 (예: 크산토스 → char_4166_varkis
"…· 오퍼레이터 바르카리스", 레나 → char_1022_flwr2 "…· 오퍼레이터 퍼퓨머 더 디스틸트").
스프라이트 파일명(avg_4166_varkis 등)이 오퍼 id의 힌트가 되니 대조해 볼 것.

**썸네일 서버판**: CN판은 중국어 부제가 있어 금지. ko=한국판(`build-story.py
--kr-thumbs` — KR 공식 CDN 언팩, pip UnityPy·lz4inv 필요), en=본가 en 브랜치(`thumbEn`),
ja=555me/ArknightsAssets2 jp 브랜치(`thumbJa`). 신규 이벤트 추가 시 기본 모드 실행 후
--kr-thumbs로 한국판을 덮어쓸 것 (기본 모드는 글로벌판을 임시로 넣는다).
