# 새 화면 추가 점검표

새 메뉴를 붙일 때마다 **같은 항목을 같은 순서로 빠뜨려 왔다.** 기능은 잘 만들어 놓고
딥링크가 튀거나, 소개 페이지에 빈 칸이 남거나, EN/JA에 한국어가 그대로 나가는 식이다.
아래는 실제로 사고가 났던 것만 모은 목록이다 — 짐작이 아니라 전부 사후 기록이다.

## 0. 만들기 전에 정할 것

- **경로인가 해시인가.** 최상위 메뉴는 **경로**(`/autochess`)로 만든다 — 프리렌더가 그
  화면으로 되고 색인·공유·첫 페인트가 전부 공짜로 맞는다. 한 화면 **안**의 탭·필터·모달만
  해시로 둔다 (§1이 그 대가다).
- **파일 수 예산.** Cloudflare Pages 배포 한도가 20,000개고 여유가 3천 안팎이다. 상세
  페이지를 라우트로 만들면 항목 1개당 6파일(html+rsc × 3언어)이다 — 수백 개짜리 목록은
  개별 라우트를 만들지 말고 목록+모달로 간다 (docs/PROJECT-GUIDE.md 참고).

## 1. 딥링크 첫 페인트 가리개 ★ 가장 자주 재발

프리렌더 HTML은 **URL 해시를 볼 수 없다.** 그래서 `/autochess#item`으로 바로 들어오면
서버가 그려 둔 **기본 탭(맹약)이 먼저 보였다가** 하이드레이션 뒤 아이템으로 튄다.
느린 폰에서는 1초 넘게 잘못된 화면을 본다. 네댓 번 고쳤는데 새 메뉴가 생길 때마다 재발했다.

해시로 화면을 고르는 컴포넌트는 **세 가지를 다 갖춰야 한다**:

1. 해시가 정하는 영역을 `<div data-hashswap>` 로 감싼다 (탭 바까지 포함 — 탭 하이라이트도 틀리다)
2. 해시 반영을 `useEffect`가 아니라 **`useLayoutEffect`** 에서 한다
3. 반영 직후 `document.documentElement.removeAttribute("data-hashboot")`

가리개 자체는 이미 깔려 있다 — `app/layout.tsx`의 pre-paint 스크립트가 해시가 있으면
`html[data-hashboot]`을 세우고(4초 안전 해제 포함), `app/globals.css`가
`html[data-hashboot] [data-hashswap] { visibility: hidden }`으로 가린다.
`visibility`라서 자리는 그대로 잡혀 CLS가 없다.

`npm run build`의 **`scripts/check-hashboot.mjs`가 이걸 강제한다.** `location.hash`를 읽는
`app/**/*.tsx`인데 셋을 안 갖추면 빌드가 멈춘다. 해당 없는 화면은 그 스크립트의 `EXEMPT`에
**이유를 적어** 넣는다 (예: 록라는 프리렌더가 '불러오는 중' 자리표시자뿐이라 플래시가 없다).

⚠ 전역 모달 해시(`#changelog`·`#broadcast` 등)는 페이지 화면을 바꾸지 않으므로 가리개
대상이 아니다 — pre-paint 스크립트의 제외 정규식에 이미 들어 있다.

## 2. 딥링크 자체

- 필터·탭 상태는 `replaceState`(히스토리를 안 쌓는다), **모달이 새로 열릴 때만** `pushState`
  (뒤로가기로 닫힌다). 록라(`app/rogue.tsx`)·위수 협의(`app/autochess.tsx`)가 같은 규약이다.
- ⚠ `location.hash = "#…"` **대입 금지.** vinext의 RSC 내비게이션을 타는데 Pages 정적
  배포에선 페이로드를 못 받아 무한 재시도에 빠진다 (라이브 실측: 클릭 1회에 내비 75회).
  `History.prototype.pushState.call(history, …)` + `dispatchEvent(new Event("hashchange"))`.
- ⚠ `history.pushState`는 vinext가 **인스턴스 패치**해 스크롤을 맨 위로 리셋한다. 해시만
  바꿀 땐 네이티브 프로토타입을 직접 부른다. (`replaceState`는 패치돼 있어도 안전 — 실측)
- **빈 해시 = 기본 상태**로 되돌려야 한다. 그냥 `return`하면 뒤로가기로 해시가 지워져도
  모달이 안 닫힌다 (2026-08-24 실제 버그).
- 전역 모달 해시가 떠 있으면 페이지 해시 기계가 **자기 상태로 덮어쓰지 않는다** —
  `GLOBAL_MODAL_HASH`(app/hash-modal.ts) 가드를 apply·writer 양쪽에 건다.

## 3. 3개 언어

- **한국어 UI 문구를 쓰면 `app/i18n.tsx` 사전에 같은 키를 추가**한다 (`t()`는 없으면 키를
  그대로 뱉으므로 조용히 한국어가 나간다). 데이터에서 온 이름은 사전 대상이 아니다.
- 로케일별 데이터가 있으면 `build-i18n.py`까지 돌린다 (CLAUDE.md 규칙).

## 4. 모달은 공용 창(ModalWindow)

새 모달은 `app/modal-window.tsx`의 `ModalWindow`를 쓴다 — 백드롭·스크롤·Esc·창끼리 앞뒤(z)·
이동·크기 조절·📌 고정이 전부 딸려 온다. 자체 백드롭을 만들면 그 기능이 통째로 빠진다
(록라 모달 8종이 그래서 2026-08-24에 뒤늦게 이관됐다).

- 겹쳐 뜬 창을 **앞으로** 가져오려면 `key`를 주어 리마운트시킨다 (z는 마운트 때 정해진다).
- 창 안에 자체 `Esc` 핸들러를 남기지 말 것 — 📌 고정한 창도 Esc로 닫힌다.
- 카드가 통째로 `<button>`인 목록에는 **버튼을 중첩할 수 없다** (하이드레이션 오류). 링크는
  모달 안에서만 단다.
- body 포털이라 **페이지 안쪽 CSS 변수를 못 받는다.** 테마 변수는 `html`에도 걸어야 한다
  (록라 `.rg.rgN, html.rg-theme.rgN`).

## 5. 소개 스샷·OG — 세 곳

기능 화면이 하나 늘면 세 곳을 같이 고쳐야 한다. 하나만 빠뜨리면 소개 페이지에 빈 칸이
남거나 공유 카드 이미지가 404가 된다 (위수 협의가 실제로 그랬다).

1. `scripts/capture-about.mjs` SHOTS — 촬영 대상
2. `app/about.tsx` SHOTS 맵 + `SHOT_VER`를 오늘 날짜로
3. `scripts/build-og.py` TAB_META·SUBLINE — `/og/<locale>/<tab>.jpg`

촬영 뒤 `node scripts/r2-sync.mjs`까지 돌려야 라이브에 나간다 (스샷·OG는 Pages가 아니라
R2에서 서빙). 상세 절차는 **about-shots** 스킬.

## 6. SEO

`app/seo.ts`에 제목·설명(3개 언어)을 넣는다. 사이트맵·robots·JSON-LD는 경로 기준으로
자동이지만, **OG 이미지는 자동이 아니다**(§5-3). 설명문의 수치(종류 수 등)는 데이터가
바뀌면 같이 낡으므로 큰 데이터 정정 뒤에는 다시 본다.

## 7. CSS 함정 (전부 실제 사고)

- **`font:` 단축 속성에 `inherit`을 섞지 말 것** — `font: 700 11px/1 inherit`은 무효라
  통째로 무시된다. 한 달간 반복된 버그라 `scripts/check-css.mjs`가 빌드에서 막는다.
- **`--paper`는 페이지 바탕색 그 자체다.** 카드 배경에 쓰면 라이트 모드에서 배경과 겹쳐
  그 카드만 투명해 보인다. 카드 표면은 `--white`, 한 단계 눌린 면은 `--bg-faint`.
- **`--chip`은 글자 칩 배경이 아니다** — 이미지 뒤에 까는 어두운 판이고 라이트에서 잉크색과
  같다. 글자에 쓰면 검정 배경 + 검정 글씨가 된다.
- 라이트/다크 **양쪽 스크린샷**으로 확인한다. 흰 글리프 아이콘은 라이트에서 반전이 필요하다.
- 미디어쿼리는 `min-width`/`max-width`만 — `width>1180px` 신문법은 빌드가 죽은 규칙으로 만든다.

## 8. 마무리

- `npm run build` 통과(check-css·check-hashboot 포함) + 변경 파일 eslint 신규 에러 0.
- **딥링크로 직접 진입 / 뒤로가기 / 새로고침 / 모바일 폭**을 실제로 눌러 본다.
- 3개 언어 페이지를 열어 콘솔 에러 0인지 본다.
- 업데이트 내역(`/changelog`) 등록은 사용자와 문구를 맞춘 뒤. 같은 날짜 안에서는 **나중 작업이 위**.
- 빌드 확인 → 커밋 → push 까지만. **`bash scripts/deploy.sh`는 돌리지 않는다** (CLAUDE.md).
